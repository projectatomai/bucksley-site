How it works

The Bucksley app runs as an MCP server when your agent starts it with --mcp. It talks over standard input and output, on your Mac only, and works on the same local workspace the app shows. Changes appear in the app right away and are listed under Settings → Agents.

You stay in control. Agents can only read until you turn on Let agents make changes in Settings → Agents, and every change they make is logged in the app. Bank secrets and AI keys stay in the Keychain and are never passed to an agent as tool arguments. Bucksley is read-only with your banks, so no tool can move money.

Claude Code

Add Bucksley as a local server for your user or project:

claude mcp add bucksley -- /Applications/Bucksley.app/Contents/MacOS/Bucksley --mcp

Codex

Add this to ~/.codex/config.toml:

[mcp_servers.bucksley]
command = "/Applications/Bucksley.app/Contents/MacOS/Bucksley"
args = ["--mcp"]

Claude chat

In the Claude desktop app, open Settings → Developer → Edit Config and add a bucksley entry under mcpServers with the same command and the --mcp argument. Restart Claude.

Tools

Ten tools read. Eight make changes, and stay off until you allow them.

ToolWhat it does
get_statusWhich connections are set up, how many accounts and transactions there are, and when each last synced.
list_accounts · get_net_worthAccounts with balances, and net worth over time by what it is made of.
list_transactionsSearch and filter transactions by date, account, category, amount, tag or review state.
get_spendingSpending by category or group for any period.
list_categories · list_rulesYour categories, groups and the rules that file transactions.
list_budgets · list_recurringBudgets with spent, left and pace, and recurring bills and subscriptions.
get_review_queueTransactions waiting for review.
mark_reviewed · set_category · set_note · rename_transaction · set_tagsTidy up transactions. Off until you allow changes.
create_rule · set_budgetAdd a categorization rule or set a budget. Off until you allow changes.
sync_nowFetch new transactions from your connections now. Off until you allow changes.
