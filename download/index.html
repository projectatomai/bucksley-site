How to install Bucksley

  1. Open the disk image.

    Open Bucksley-0.1.12.dmg in Downloads. Drag Bucksley into Applications, then eject the disk image.

  2. Launch Bucksley from Applications.

    If macOS asks for confirmation, choose Open.

  3. Connect your accounts.

    Use your SimpleFIN Bridge setup token or your own Plaid keys, or import a CSV from another finance app. Connection secrets are saved in the Keychain.

  4. Review and budget.

    Bucksley files new transactions by category. Mark them reviewed, add rules and set budgets. Or connect an agent and let it help: see MCP setup.

Automatic updates. Bucksley checks for new versions and installs signed updates for you. You can also choose Check for Updates from the Bucksley menu.

Verify your download

In Terminal, run shasum -a 256 ~/Downloads/Bucksley-0.1.12.dmg and compare the result with this SHA-256 checksum.
